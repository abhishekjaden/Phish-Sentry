About PhishSentry 📖

AI-powered security for everyone

Advanced AI Security

Protecting users from cyber threats through intelligent analysis, explainable AI, and comprehensive cybersecurity education

Our Mission

PhishSentry is dedicated to protecting individuals and organizations from increasingly sophisticated phishing attacks. Our AI-powered platform combines cutting-edge machine learning models with user education to create a comprehensive defense against cyber threats.

We believe that cybersecurity should be accessible to everyone, regardless of technical expertise. Our system provides clear explanations and educational resources to help users understand and identify threats independently.

Key Objectives

Detect phishing with high accuracy
Educate about security practices
Provide explainable AI insights
Maintain privacy and security

How It Works

1

Content Submission

Users submit email text or URLs for analysis through our secure interface.

2

AI Analysis

Our RoBERTa text model and XGBoost URL model analyze content using machine learning.

3

Explainable Results

For email text, SHAP analysis reveals which words drove the phishing verdict.

4

Education & Learning

Interactive quizzes and chatbot help users improve their cybersecurity awareness.

Core Features

Email Analysis

RoBERTa-powered NLP detects phishing patterns in email content with high accuracy and detailed explanations.

URL Security

XGBoost model examines 20+ URL features to identify malicious links and suspicious domains.

SHAP Explainability
